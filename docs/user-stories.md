# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a SME owner, I want to select my business type, so that the system can process and analyse suitable location for my business based on my preferrence and need. (NFR 1)
    Acceptance Criteria:
    i) The system allow user to select type of business, for example cafe
    ii) The system uses the selected business type to analyse the suitablelity of market and location

2. As a SME owner, I want the system to analyse market patterns across different districts, so that I can identify which location suitable to operate my business. (NFR 2)
    Acceptance Criteria:
    i) The system analyse related data (hosuehold income,existing business,rental pricing) of the district
    ii) The system show the data analysis to user and help for comparing between district

3. As a SME owner, I want to view the ranking of the business locations, so that I can compare the market opportunities before choosing location. (NFR 2)
    Acceptance Criteria:
    i) The system rank the business location based on selected criteria using TOPSIS method
    ii) The system display the descripton of reasoning behind ranking of each location to user
