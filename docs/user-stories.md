# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a SME owner, I want to select my business type, so that the system can process and analyse suitable location for my business based on my preferrence and need.
2. As a SME owner, I want the system to analyse market patterns across different districts, so that I can identify which location suitable to operate my business.
3. As a SME owner, I want to view the ranking of the business locations, so that I can compare the market opportunities before choosing location.
