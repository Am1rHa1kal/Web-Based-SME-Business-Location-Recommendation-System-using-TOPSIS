# Requirements

## Functional requirements (what the system must DO)
1. The system shall enable user to enter business type, business budget and preferred criteria
2. The system shall enable user to find suitable business locations according to selected district and selected criteria
3. The system shall uses TOPSIS to rank potential business location with description
4. The system shall consider nearby business type when evaluating location
5. The system shall display the analysis result on interactive map with a ranked table for comparison purpose

## Non-functional requirements (how the system must PERFORM)
1. The system shall display the filtering result within 3 second under normal circumstance
2. The system shall allow user to complete the process without requiring complex knowledge
3. The system shall display interface correctly on common desktop and mobile device
