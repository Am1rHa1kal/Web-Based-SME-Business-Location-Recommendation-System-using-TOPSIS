# OUTLINE OF TECHNOLGY
- AHP Used for weighting criteria by using pairwise comparisons so the user can compare between pair of criteria at a time where the criterion with the biggest value of weight mattered the most to the user.

- TOPSIS use numeric criteria values which usually rise or fall in one direction and can be compared as compared units which explain why it need to be normalised, the idea is when the best location closest to ideally best solution and furthest from the worst solution.

- Open data sources use to provide the data related for program, for example household income, shop locations and LRT station’s locations which later be used to be processed until rank of location obtained

- Progressive Web Application use to deliver the functional program through available browser on mobile device and desktop
